# MCP 由用户自负审查，应用不设白名单

MCP server 是可执行程序，但学院对用户添加的 MCP **不审查、不设白名单、不拦截**，只标来源并在首次下发时确认一次；自定义 tool 代码仍然不开放。理由是自用产品里白名单约等于自己给自己发许可证（07 票的白名单从未实现，说明它本来也没被需要），而「MCP 是配置 + 用户自带的外部程序」与「tool 是应用替你加载并执行任意 JS」是两件事，后者仍被 05 票否决。

## Consequences

- 一个恶意 MCP 会以该员工的权限执行；这是明确接受的风险，不再作为回归项讨论。
- 来源标记（本机 / 远端 / 手写）是事后唯一可查的线索，属于必做项而非可选项。
- 与 07 票的「MCP 白名单」冲突：那条从票面删除，改为「来源标记 + 首次确认」。

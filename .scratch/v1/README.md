## 怎么取票

**frontier** = 编号最小的、`Status: ready-for-agent` 的、且 Blocked by 全部完成的票。

取一张：把该文件 `Status:` 改成 `in-progress`，完成后逐条勾选验收项并改成 `done`，再回来取下一张。

## 与决策票的区别

- `.scratch/cubicle/issues/` = **决策票**（wayfinder，15 张已全部关闭，回答「为什么这样做」）

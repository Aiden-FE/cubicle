# 03: 招聘第一个员工

**What to build:** 点空工位打开招聘三步（选预设角色 → 看能力清单 → 确认录用），录用后工位被占用、角色出现在工位上；角色定义按招聘时刻的快照保存，之后改角色不影响已招的人。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 三步可前进/后退，能力清单展示人格、技能、工具、引擎与成本
- [ ] 录用后工位从「空」变「占用」，办公室里出现该员工
- [ ] 重启后员工仍在，且角色快照与录用时一致
- [ ] 同一角色可再招一人，坐不同工位
- [ ] 招聘过程不写任何用户家目录下的引擎配置

# 09: 上下班

**What to build:** 公司有上下班时间表，到点自动「上班」激活有未完成任务的员工；手动按钮可立即 override；「下班」后 90 秒宽限、落盘暂停，再上班能续跑；退出程序时三选（直接退 / 等完成 / 取消）。

**Blocked by:** 06

**Status:** in-progress

- [ ] 应用运行时，时间表到点自动上班（可配上下班时刻）
- [ ] 手动 override 立即生效，且不改动时间表
- [ ] 下班后任务进入暂停态，重启后仍可续跑
- [ ] 退出时出现三选对话，直接退会先执行下班落盘
- [ ] 暂停期间不再产生新的工具调用

# 07: 工位动画

**What to build:** 员工的状态由真实事件驱动：读文件 / 写代码 / 跑测试 / 被拦 / 请示 / 闲时各有动画与屏幕画面；空闲会摸鱼，久了会起身去倒咖啡再回来。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 四类工具状态正确映射（读 / 写 / 执行 / 测试），屏幕画面随状态切换
- [ ] 测试失败屏幕变红、通过变绿
- [ ] 被策略拒绝时工位有可见提示，不静默
- [ ] 空闲 9 秒摸鱼、45 秒去咖啡并返回工位
- [ ] 名牌与气泡可开关；关掉后仍能看出「在忙/在闲」

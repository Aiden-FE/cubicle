# 04 — 模型与成本策略

Type: grilling
Status: resolved
Blocked by: 03

## Question

员工干活用哪家模型、谁来付钱、成本怎么控？

## 要拆清楚

- **供应商**：DeepSeek / Anthropic / OpenAI / 本地模型。pi 的 provider 抽象都支持，切换成本多大？
- **引擎与模型的关系**：引擎自带模型路由（统一协议见 14 票）—— 员工是先选引擎再选模型，还是先选模型再按模型荐引擎？
- **鉴权**：BYOK（用户自己填 key）还是应用内置（你出钱）？v1 自用的话，最可能是 BYOK + 一个默认推荐。
- **按角色分模型**：程序员用强模型、文案用便宜模型？还是全公司一个模型？
- **成本可见性**：要不要在 UI 上显示每个员工 / 每个任务的 token 与花费？Marvis 是在工位头顶直接显示 Token 计数的。
- **预算闸门**：单任务上限、单日上限，超了怎么办（暂停 / 降级 / 通知）？
- **上下文策略**：pi 有压缩与会话树；长任务怎么避免上下文爆掉、怎么控成本？

## 要产出

默认 provider 与模型矩阵（角色 → 模型）、鉴权方案、成本计量与展示方式、预算闸门规则。

## 备注

v1 自用，先别设计计费系统；但「成本可见」最好从第一天就有，否则多员工跑起来会失控。

## Answer

**结论：路由「先引擎后模型」，引擎是主键；v1 默认引擎 = pi（内置依赖），本机已登录的 Codex「探测到即用」；成本 v1 只聚合 token（任务 / 员工 / 公司三层），单任务默认软闸门；key 与登录统一在「设置页 · 引擎中心」；上下文压缩用引擎自带的机制。**

### 1. 路由：先引擎后模型

`员工配置 = { engine_id, model, params }`，模型清单来自所选引擎的能力卡片（14 票的适配层会暴露）。角色模板带**推荐组合**（引擎 + 默认模型），招聘界面可改。不做「先模型反推引擎」—— 跨引擎模型等价表永远对不准。

### 2. 鉴权：BYOK 是架构事实

应用不内置任何 key、不代充值（与 14 票「只调用用户自装引擎」一致）。配置统一收在**设置页 · 引擎中心**：

- **pi**：在设计中的引擎列表里，用户填 API key（存应用私有目录，不写 `~/.pi`，同 03 票隔离原则）。
- **codex**：本机已验证可用 —— `codex.exe` 在 PATH，`~/.codex/auth.json` 与 `config.toml` 已存在 → 探测到即绿徽章，零配置。
- **dsh**：检测到桌面版即绿徽章（CLI 随应用内 runtime 提供）。
- **claude / qoder / gemini**：本机未装 → 灰徽章，显示安装引导，不消失。

招聘界面只读徽章：绿 = 可用；灰 = 「去引擎中心配置」跳转，不打断三步招聘。

### 3. v1 默认绑定

预设角色（程序员 / 测试 / 产品经理）出厂统一绑 **pi + 用户在引擎中心配置的默认模型**；首次派任务前引擎中心引导配置。Codex 绿徽章时亦可一键切换为该员工引擎。

### 4. 成本计量与展示

- 只显示 **token**（v1 不做换算钱 —— 多引擎价目不可靠，订阅制无法折算单价；费用换算留 v1.1 雾）。
- 来源：归一化事件里的 usage 字段（pi / Claude 粒度最全）。粗粒度引擎缺失 usage → 计 0 并标「未计量」，UI 上可见区别。
- 聚合三层：**任务侧边栏**（本任务 token）/ **员工名牌**（本日累计角标，可选显示）/ **公司面板**（全部员工累计）。

### 5. 预算闸门（软）

单任务默认上限 **50 万 token**（可在角色或任务上改）：到 80% 头顶黄点提示「预算紧张」；到 100% 巡位暂停 + 「继续（+50%）」按钮。硬闸门（审批式）押后到 07 票。

### 6. 上下文策略

用引擎自带压缩 / 会话机制（pi 有会话树压缩，其余各家同理），应用层不建统一压缩器。13 票的「下班暂停 / 上班续跑」不得依赖应用层压缩，只依赖会话实体的恢复指针。

### 验收口径（进 01 票判据的补充）

任务跑完，侧边栏能看到「本任务消耗 token：N」；公司面板能看累计。

### 交接

- 引擎中心的页面与信息架构 → 10 票
- 适配层如何拿 usage / 能力徽章 → 14 票
- 本机探测事实（2026-11-05）：codex=已装已登录；dsh=桌面 runtime 在；pi=随应用内置（常驻可选）；claude / qoder / gemini=未装。

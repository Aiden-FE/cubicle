## Answer

**结论：开场 = B 三步向导；招聘 = 中屏弹窗；主界面 = 稿 2「后台轨」为骨架 × 稿 1「右缘任务把手」为筋的杂交；公司切换器 = 左轨头像菜单；设计系统定为暖纸面 + 三语义色 + 克制动效。**

### 1. 首次启动（定案：B 向导）

三步：欢迎特性页 → 公司信息（名称）→ 项目组模板卡（每模板标明预置角色 / 工位 / 工作区）→ 进入办公室落座。A 一张卡与 C 零配置退役，但 C 的「空态渐进披露」精神保留为 B 的兜底：**向导所有步骤可跳过**，进入办公室后由空态卡渐补（原型 C 变体已验证此模式）。

### 2. 主界面骨架（1 × 2 杂交）

```
左轨 56px         办公室画布 100%     右缘把手
┌──┬──────────────────────────────┬───┐
│星 │   娃娃屋办公室（09 票）      │ ▸3│ ← badge=活跃工单数
│✉3 │                             │   │   拉开 356px 抽屉：
│👥 │                             │   │   进行中/待验收/档案 三段
│⚙ │   ◯ 输入框（悬浮胶囊）[派活]  │   │   点卡展开四件套（06 票）
└──┴──────────────────────────────────┴───┘
```

- **左轨**（稿 2）：公司头像「星」→ 公司菜单（含切换语义标注，13 票）；✉ 工单台（396px 浮层：工单卡 + 状态徽章 + 进度条）；👥 花名册；⚙ 引擎中心。
- **右缘把手**（稿 1）：拉出即有活的所有工作；badge = 活跃工单数。
- **区域规则**：工单创建 = composer 内 playbook 卡（08 票）；工单列表 = 把手抽屉 / 工单台浮层；**主画布永远 100% 办公室，任何 management 件都可收起**。
- 空工位「＋ 招聘」呼出招聘弹窗（中屏，定案）。
- 顶栏只留一到两枚状态胶囊（上班中 · 工位占用），其余全撤。

### 3. 设计系统（五稿原型实测）

- 色板：纸面 `#FAF9F6` / 面板 `#FFF` / hairline `#E7E4DE` / 文本 `#23262A`+`#8A8F98`；**语义色仅三**：进行中 `#E2574C`、成功 `#1E7C46`、等待 `#B46A00`；主按钮炭黑 `#25282C`。
- 字体：系统栈 + tabular 数字；圆角面板 12 / 卡 10 / 胶囊 999；阴影 1/3/8px 三级；动效 150–220ms ease-out，`prefers-reduced-motion` 兜底。
- 办公室内的美术语言由 09 票管辖（canvas 层名牌 / 气泡）。
